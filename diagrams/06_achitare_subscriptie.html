MovyAI · Pricing Page · Flux planificat — Starter / Pro / Studio

sequenceDiagram actor U as User participant HP as Header / Nav participant PP as Pricing Page participant PAY as Payment Processor participant BE as Backend API participant AC as AuthContext U->>HP: Click "Pricing" din navigatie HP->>PP: Navigheaza la /pricing PP-->>U: Afiseaza planuri — Starter 0$, Pro 19$/luna, Studio 49$/luna alt Starter — plan gratuit U->>PP: Click "Get started" PP->>BE: POST /api/subscription { plan: starter, userId } BE-->>PP: { success: true } PP-->>U: Confirmare activare plan Starter else Pro — 19$ pe luna U->>PP: Click "Start Pro" PP->>PAY: Initializeaza sesiune plata (Stripe) PAY-->>U: Formular plata — card si date facturare U->>PAY: Completeaza si confirma plata PAY->>BE: Webhook: payment_success { userId, plan: pro } BE->>BE: Actualizeaza subscriptia utilizatorului BE->>AC: Actualizeaza user.role si plan BE-->>PP: Redirect catre success URL PP-->>U: Confirmare abonament Pro activ else Studio — 49$ pe luna (Contact Sales) U->>PP: Click "Contact sales" PP-->>U: Formular contact sau calendar meeting U->>PP: Trimite cerere PP->>BE: POST /api/contact { userId, plan: studio } BE-->>U: Email confirmare — echipa va lua legatura end
Nota: Aceasta diagrama reprezinta fluxul planificat. In prezent pagina /pricing contine doar UI static — butoanele nu sunt conectate la un backend de plati. Fluxul reflecta implementarea recomandata cu Stripe sau un processor similar.
